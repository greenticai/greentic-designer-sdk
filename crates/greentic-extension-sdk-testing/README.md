# greentic-extension-sdk-testing

Test utilities and fixtures for [Greentic Designer](https://greentic.ai) extensions.

Fixtures and helpers for testing extensions and SDK consumers: build a
valid extension tree, pack it into a `.gtxpack`, and stub a registry.

Intended as a `[dev-dependencies]` entry.

Part of the [greentic-designer-sdk](https://github.com/greenticai/greentic-designer-sdk)
workspace — see the repository README for the full workflow.
